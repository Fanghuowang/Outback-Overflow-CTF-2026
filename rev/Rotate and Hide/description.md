# Rotate and Hide

- **Category:** rev
- **Points:** 100
- **Difficulty tags:** easy
- **Author:** Sphynx
- **Solves:** 105

## Description

This Go program asks for the flag and tells you whether you got the flag right.
Your task is to try and reverse engineer the program and recover the flag

Flag format: `OO{...}`

## Hints

- Each byte is only rotated and XORed with a constant. Both operations are invertible.
